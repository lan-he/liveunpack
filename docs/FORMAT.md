# 提取格式说明

当前实现面向 JPEG 文件中附加完整 ISO Base Media File Format / MP4 资源的动态照片。

1. 验证输入以 JPEG SOI 字节 `FF D8` 开头。
2. 搜索 `ftyp` 标记，回退四字节定位候选 box 起点。
3. 检查 box 长度和边界，支持普通 32 位长度、64 位扩展长度，以及延伸到文件末尾的零长度 box。
4. 要求连续有效 box 中包含 `ftyp`、`moov`、`mdat`。
5. 如果源文件前部 XMP Container Item 声明的视频长度与候选起点及文件结尾吻合，保留完整声明资源，包括厂商尾部数据。否则复制完整解析到的 box 区间。
6. 输出原始字节，并计算 SHA-256。

此策略已对提供的 vivo X500 Pro Max 样本验证。它不实现全部 Motion Photo 元数据规范，也不保证任意 JPEG+MP4 拼接或全部厂商格式均可识别。现阶段不解析 HEIC，不处理独立 MOV 配对，不重建丢失或被截断的视频。

顶层结构检查不等于完整媒体解码验证。合成测试用于验证边界和文件处理逻辑，真实设备兼容性应通过原始照片提取及播放验证。
