# LiveUnpack · 拾帧

**把动态瞬间，原样带走。**

批量提取动态照片里的原始 MP4 · 无转码 · 本机处理 · 零第三方运行依赖

[快速开始](#快速开始) · [兼容性](#兼容性) · [命令行](#命令行) · [常见问题](#常见问题) · [参与贡献](CONTRIBUTING.md)

</div>

---

手机拍下的一张动态照片，可能同时保存了静态画面和一小段视频。LiveUnpack 将 JPEG 里内嵌的 MP4 原样取出，让这些瞬间可以独立保存、播放和剪辑。

项目起源于 vivo X500 系列动态照片的批量导出需求。**目前仅测试过 vivo X500 系列；OPPO 理论上可支持，但尚未实机验证。** 是否能够提取取决于具体文件结构，不以手机品牌作为识别依据。

## 功能

- **原始视频导出**：直接复制内嵌 MP4 字节，不解码、不转码、不重新压缩。
- **批量处理**：选择多张 JPG/JPEG、多个 ZIP，或递归扫描整个文件夹。
- **本地浏览器界面**：拖入文件、设置输出目录、查看处理进度和结果。
- **同名保护**：自动生成 `photo_1.mp4`、`photo_2.mp4`，避免覆盖已有文件。
- **错误隔离**：普通照片或损坏文件会显示失败，其余文件继续处理。
- **命令行与报告**：支持 JSON 结果、SHA-256 校验值及退出码，方便脚本调用。
- **轻量运行**：Python 标准库即可运行，无需 FFmpeg 或第三方 Python 包。

## 兼容性

| 来源 / 格式 | 状态 | 说明 |
| --- | --- | --- |
| vivo X500 系列动态照片 | 已测试 | 项目维护者已测试该系列；开发验证样本来自 X500 Pro Max |
| OPPO 动态照片 | 理论支持，未验证 | 如果 JPEG 内嵌完整 MP4 且结构兼容，可能可以直接提取 |
| 其他 Android Motion Photo | 未验证 | 欢迎提交兼容性反馈，不保证全部机型或系统版本可用 |
| 普通 JPG / JPEG | 无视频可导出 | 显示跳过/失败 |
| iPhone Live Photo（独立 HEIC + MOV） | 不支持此组合提取 | 视频通常作为独立 MOV 文件存在 |
| HEIC / HEIF 内嵌视频 | 暂不支持 | 当前仅识别 JPEG 输入 |

保留手机导出的**原始文件**。聊天软件压缩、截图、图片编辑或某些相册导出方式，可能移除视频部分。ZIP 只是打包方式，无法恢复已丢失的视频。

操作系统：macOS 已本地验证；Windows、Linux 提供启动脚本与自动测试配置，图形界面尚未实机验证。要求 **Python 3.9 或更新版本**及现代浏览器。

## 快速开始

### 1. 获取程序

从本仓库的 **Code → Download ZIP** 下载并解压，或使用 Git 克隆本仓库。程序支持直接运行，不需要安装 Python 依赖。

### 2. 启动

| 平台 | 启动方式 |
| --- | --- |
| macOS | 双击 `启动导出.command`，或在项目目录运行 `python3 live_export.py` |
| Windows | 双击 `start.bat`，或运行 `py -3 live_export.py` |
| Linux | 运行 `sh start.sh`，或运行 `python3 live_export.py` |

如果尚未安装 Python，请从 [Python 官方网站](https://www.python.org/downloads/) 安装。Windows 安装时建议勾选将 Python 加入 PATH。

### 3. 选择并导出

1. 浏览器自动打开本机界面。
2. 选择 JPG / ZIP 文件，或者点击「选择整个文件夹」扫描子文件夹。
3. 设置视频保存位置，默认是启动目录下的 `导出视频`。
4. 点击「开始导出」，等待完成后打开输出目录查看 MP4。

拖放支持文件；文件夹请使用「选择整个文件夹」。输出会集中保存在指定目录，不保留原来的子目录层级；同名文件自动编号。重复导入同一照片会生成新的编号文件，不会自动去重。

关闭启动时的终端窗口，或按 `Ctrl+C`，即可退出本地服务。只关闭网页不会退出服务。

## 命令行

```bash
# 单张照片
python3 live_export.py photo.jpg -o output

# 多个输入、ZIP、递归扫描文件夹
python3 live_export.py photo.jpg photos.zip ./photos -o output

# 保存处理报告（包含输出路径、大小、SHA-256）
python3 live_export.py ./photos -o output --report reports/result.json

# 不自动打开浏览器，手动打开终端显示的本机链接
python3 live_export.py --no-browser

# 查看版本和参数
python3 live_export.py --version
python3 live_export.py --help
```

Windows 将 `python3` 换成 `py -3` 或 `python`。含空格的路径请用引号括起来。

命令行每个处理结果输出一行 JSON。全部成功返回 `0`；存在失败、跳过或没有可处理文件返回 `1`。报告选项仅用于命令行批处理。

也可选择安装本地命令：

```bash
python3 -m pip install .
liveunpack ./photos -o output
```

安装构建阶段需要 setuptools；直接运行脚本没有第三方依赖。目前不提供 PyPI 安装承诺，请从此仓库获取源码。

## “无损”具体指什么？

这里指**提取原本已经存在的 MP4 字节**。程序不会重新编码视频，原视频的分辨率、帧率、编码、声音及包含在 MP4 资源里的元数据都会随提取内容保留。它不会提升手机原本录制的画质，也不会把静态照片的高像素分辨率变成视频分辨率。

在提供的 X500 Pro Max 样本上，提取结果为 3,116,894 字节，HEVC 视频 1920 × 1440，约 1.568 秒，含 AAC 音频；导出结果与源文件中的视频资源逐字节一致。该数值只代表此样本。

程序检查 MP4 顶层 box 的边界与必要结构，不完整解码验证每一帧；异常文件仍可能无法播放。实现细节见 [格式说明](docs/FORMAT.md)。

## 隐私与处理限制

- 文件只通过本机浏览器发送到 `127.0.0.1` 本地服务，没有云端上传、统计或外部资源请求。
- 服务使用临时会话令牌，只监听本机。它是个人桌面工具，不应部署为公共网站或转发到局域网。
- 不改写输入照片；ZIP 成员直接在内存中读取，不按压缩包内路径解压到磁盘。
- 单个输入上限 **512 MiB**；ZIP 内单张照片上限 **256 MiB**。处理时需要将单个输入装入内存，大批量建议直接选择照片文件夹。
- 不会移除内嵌视频元数据；分享导出的视频前，请按个人需要检查其中的信息。

## 常见问题

**为什么找不到视频？** 先确认是手机原始动态照片，并且没有经过压缩或编辑。普通 JPG 不包含视频；新的动态照片格式也可能暂不兼容。

**为什么导出后只有一两秒？** 程序保留照片内嵌片段的实际时长，不补帧、不延长。

**MP4 播放器打不开？** 手机视频可能采用 HEVC 等编码。可尝试支持该编码的播放器。程序不自动转为 H.264，以避免重新压缩。

**OPPO 一定可以吗？** 不能保证。目前只有结构上的兼容预期，没有 OPPO 实机测试结论。欢迎提供机型、系统版本、成功或失败结果。

**macOS 双击没反应？** 先在终端运行 `python3 --version`，确认 Python 可用；再进入项目目录运行 `python3 live_export.py` 查看提示。保留终端窗口直到处理结束。

**ZIP 很大怎么办？** 先用系统解压工具解压到文件夹，再通过「选择整个文件夹」处理。
